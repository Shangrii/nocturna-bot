<objective>
Fix the phase's one genuinely-new security defect and land the vanity-URL namespace guard, both backend-only:

1. **Pitfall-1 tier-gate split (T-10-01, CRITICAL).** Once the "Editor" sidebar item becomes visible-but-locked to every owner/Manager (10-04), a non-editor clicking it currently hits `require_editor`, which calls `request.session.clear()` — logging owners/Managers out of the ENTIRE dashboard — and renders `login.html` instead of the `forbidden.html` dead-end. Restructure GET `/` and GET `/editor` to resolve tier via `_resolve_roles` and raise `TierForbidden(required_tier="editor")` for non-editors (no session clear, renders forbidden.html), while leaving every POST mutation endpoint on the UNCHANGED `require_editor` (D-07 freeze).

2. **Widen `RESERVED_SLUGS` (T-10-02).** The slug becomes a root-level public-site path (`nocturna-avatars.site/{slug}`); add the public site's own top-level route/static-folder words so an editor can never claim a slug that silently shadows a real site page.

Makes RED tests from 10-01 (Tasks 1 and 3) go GREEN.

Purpose: Preserve the owner > Manager > editor model and prevent both a self-inflicted logout DoS and a namespace-collision privilege issue.
Output: Split GET-route gate in `app/main.py`; widened frozenset in `core/editors_model.py`.
</objective>
