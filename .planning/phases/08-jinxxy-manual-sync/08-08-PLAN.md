     your display NAME is shown — not a numeric Discord id.

     Expect the button to be disabled there too, with the same in-flight copy — the busy state
     must survive a reload and be visible to every Manager, not just the clicker.

     "{N} nuevos · {N} actualizados · {N} quitados" or "Sin cambios.", and the last-sync card to
     update with the run time and your name.

**B — collision resolves calmly (D-01)**

     "Sincronizar catálogo" on the panel.

  8. Check the store-news channel: exactly ONE announcement embed for the change (or none, if the
     store did not change). Two embeds for one change is a defect — report it.
