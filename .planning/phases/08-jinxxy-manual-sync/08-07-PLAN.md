<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server-rendered context → browser DOM | `sync` and `products` are interpolated into the page via `tojson` |
| store_snapshot `checkout_url` → outbound anchor href | A URL from the sync flows into a clickable link |
| `/api/actions/{id}.error` → rendered status copy | Server-supplied failure text is displayed to a Manager |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-25 | Tampering | product name / category interpolation | mitigate | All product values render through Alpine `x-text` and Jinja `tojson`, never `x-html` and never raw `{{ }}` into an HTML context, so a hostile product name cannot inject markup. Enforced by the absence of `x-html` in the template. |
| T-08-26 | Tampering | external `checkout_url` anchors | mitigate | Every `target="_blank"` anchor carries `rel="noopener"`, preventing reverse-tabnabbing on links whose href comes from the upstream store. Asserted by `test_product_rows_are_seeded_into_the_page`. |
| T-08-02 | Information Disclosure | failure copy | mitigate | `statusCopy()`'s failed branch renders `this.error` only, which the server guarantees is one of three fixed bilingual categories (Plan 05), and the raw `jinxxy_sync_status.error` column is never placed in the template context (Plan 06). Asserted by `test_rendered_page_does_not_leak_the_raw_error_column`. |
| T-08-27 | Information Disclosure | product catalog in page source | accept | The seven rendered snapshot fields are already public on the live storefront and the page is `require_manager`-gated. No credentials or internal identifiers are rendered. |
| T-08-05 | Denial of Service | double-click on Sync | mitigate | The button is `:disabled` on `isBusy()`, which covers both this tab's own pending action and the mirror-derived global running state (D-05); Plan 01's enqueue dedupe and Plan 03's lock are the server-side layers. |
| T-08-SC | Tampering | frontend dependencies | accept | Zero third-party frontend dependencies are added (UI-SPEC § Registry Safety). Alpine is already vendored at `app/static/alpine.min.js`; no CDN, no new script tag. |
</threat_model>
