## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→FastAPI | Untrusted Manager request (summary body, meeting_id path param) crosses here |
| FastAPI app→bot | The app must NOT hold Discord credentials; it can only enqueue an action |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Elevation of Privilege | /meetings list/detail/republish routes | mitigate | `Depends(require_manager)` on ALL three routes — reuse the existing tier gate (owner OR Manager), never a generic auth check (ACCESS-02); grep asserts >= 3 gated routes |
| T-09-04 | Spoofing/Tampering | app performing a Discord write directly | mitigate | Router imports NO discord/bot client (grep `import discord` == 0); the only Discord side-effect path is enqueue_deduped onto the shared sqlite queue (INFRA-01) |
| T-09-02 | Tampering (IDOR) | client-supplied meeting_id targeting another meeting's post | mitigate | Payload carries only meeting_id + actor_name; the bot re-reads the forum target ids from the DB (Plan 03, Pattern 3), so a forged id cannot redirect the edit |
| T-09-07 | Denial of Service | pathologically large summary POST body | mitigate | Strip + length-cap the summary before the sqlite write (V5); Discord's 4096-char limit is the backstop applied again at rebuild time |
| T-09-SC | Tampering | package installs | accept | Zero new packages (RESEARCH Package Legitimacy Audit: N/A) |
</threat_model>
